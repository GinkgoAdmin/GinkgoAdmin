# 插件管理

## 1. 功能定位
插件管理主要面向 Web 宿主本地插件的启停、重载、配置与卸载，是前端插件运行时的管理页面。

## 2. 核心能力
- 显示插件总量、启用数、禁用数和依赖状态。
- 支持启用、禁用、重载、查看配置和卸载本地插件。
- 适配文件安装、URL 安装和开发模式安装等入口。

## 3. 使用场景
- 管理前端本地插件是否启用。
- 检查插件依赖是否加载成功。
- 在开发环境接入本地插件目录做调试。

## 4. 使用方法
- 进入「插件管理」页查看插件卡片与依赖状态标签。
- 需要排查插件异常时先看安装状态、依赖状态和是否启用。
- 需要开发态接入时使用页面提供的开发模式入口。

## 5. 快速调用
- Web 宿主管理器：`PluginManager.getInstance()`
- Web 插件类型：`PluginConfig`、`PluginAPI`
- 插件安装入口见页面中的文件、URL 与开发模式选项

## 6. 二次开发
- 新前端插件应优先复用当前插件宿主，而不是把功能直接并入主框架系统页。
- 插件配置、依赖和资源都应通过宿主 API 注入。
- Web 插件加载策略详见 [插件开发规范与流程](./插件开发规范与流程.md) 第 9 节。

## 7. 关键入口
- Web 页：`web/src/views/admin/system/PluginManager.vue`
- 宿主核心：`web/src/plugins/core/PluginManager.ts`
- 类型：`web/src/plugins/core/types.ts`

## 8. 注意事项
- 插件管理针对 Web 前端本地插件，不等同于服务端模块管理。
- 依赖失败时不一定是插件本身逻辑错，也可能是 npm/CDN 资源加载问题。

## 9. 常见问题
- 插件显示已注册但页面没变化：检查是否真的向宿主注册了钩子或组件，以及是否在正确的装载轨道（懒加载/always/portalShellNeedsPlugins）。
- 依赖状态失败：优先检查依赖声明、加载来源和浏览器控制台报错。
